## Google Search Console verification

Google Play may ask the organization to verify ownership of its website through Google Search Console. Add the HTML verification file supplied by Google to the `public` directory, commit it, and wait for the GitHub Pages deployment to finish. Then complete verification using the exact GitHub Pages URL.

The organization name, address, phone, website, and other developer details submitted to Google must remain accurate and consistent with the linked Google Payments and Dun & Bradstreet profiles.

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static website is written to `dist/client/`.
